## 📖 커리큘럼

| 단계 | 파일 | 주제 | 핵심 개념 |
|:----:|------|------|-----------|
| 1 | `INIT` | 초기 설정 | DB 생성, 테이블 설정 |
| 2 | `SELECT` | 조회 | SELECT, WHERE, ORDER BY, DISTINCT |
| 3 | `단일행함수` | 단일행 함수 | UPPER, LOWER, SUBSTR, ROUND 등 |
| 4 | `단일행-그룹함수` | 그룹 함수 | COUNT, SUM, AVG, GROUP BY, HAVING |
| 5 | `JOIN` | 조인 | INNER, LEFT, RIGHT, CROSS JOIN |
| 6 | `SUBQUERY` | 서브쿼리 | 단일행/다중행 서브쿼리, IN, EXISTS |
| 7 | `DDL` | 데이터 정의어 | CREATE, ALTER, DROP, TRUNCATE |
| 8 | `DML` | 데이터 조작어 | INSERT, UPDATE, DELETE |
